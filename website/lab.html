B Interaction lab

Feel the difference.

Three primitives, each usable by pointer, touch and keyboard. On touch screens the pointer-only effects step aside instead of misfiring.

magnetic · tilt · spotlight · createSpringValue

magnetic() · pressable() With a mouse the target leans toward the pointer within 80 px and springs home; on touch it squashes under your thumb. 0 activations

Tilt with the pointer, or use the arrow keys while focused. Escape levels it.

tilt() + spotlight() Perspective tilt and a light that follows the pointer. Keyboard: focus the pass, use arrow keys.

Press and hold with pointer, Space or Enter for one second.

createSpringValue() Hold for one second — release early and the spring rewinds. Works with Space and Enter.

  1. Discover

    You are here.

    The benches above and the studio site around them — all built with the toolkit, in the open.

    See how this site is built

  2. Install

    Give your agent the skill.

    Claude Code
    git clone https://github.com/snowbros-labs/creative-engineering
cp -r creative-engineering/skills/snowbros-creative ~/.claude/skills/
    Libraries
    npm install @snowbros/core @snowbros/motion

  3. Integrate

    Start from the project you have.

    The skill inspects your stack first and works with what is already there — GSAP, Motion, R3F, your design system. Ask it:

    /snowbros-creative audit the motion on this page and fix the worst three issues
