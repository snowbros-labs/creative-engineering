02 — Principles

Principles

Most motion on the web is decoration. We build motion that explains — what changed, where it went, what to do next. One clock drives every frame. Native scroll stays native. Reduced motion is a feature, not an afterthought. And nothing ships until it has been measured.

Causality
Every movement shows what caused it and where things went.
Frequency
The more often an action happens, the less it should move.
Interruptible
Nobody waits for an animation. Scroll, click and keys always win.
Measured
Budgets before visuals. Frame times, not adjectives.
03 — Method

From reconnaissance
to release.

  1. 01 / Recon

    Read the project before touching it.

    Detect the stack, the design system and the constraints. Prefer what the project already uses.

  2. 02 / Direction

    Three real directions, then commit.

    Genuinely different concepts with trade-offs — not three shades of the same dark gradient.

  3. 03 / Engineering

    One clock. One scroll model. Measured.

    Sticky pinning, cached layout, a single frame loop, GPU resources disposed — verified in a real browser.

04 — Toolkit

Eight packages.
Adopt one.

  • 01

    core

    One shared frame loop, easings, analytic springs, lifecycle scopes, capability and reduced-motion detection. Zero dependencies.

    @snowbros/core
  • 02

    motion

    Timelines, scroll progress, sticky pinning, scrubbing, accessible text splitting, FLIP and view transitions.

    @snowbros/motion
  • 03

    fx

    Magnetic and tilt interactions, cursors, image reveals, scramble, path drawing, marquees, flow fields.

    @snowbros/fx
  • 04

    scene

    Three.js stages with adaptive quality, scroll camera rigs, inertia, procedural materials and graceful fallbacks.

    @snowbros/scene
  • 05

    react

    Hooks and components with StrictMode-safe cleanup and no per-frame re-renders.

    @snowbros/react
  • 06

    elements

    Light-DOM Web Components for Vue, Svelte, Astro or plain HTML. Progress exposed as a CSS variable.

    @snowbros/elements
  • 07

    tokens

    Functional and expressive motion scales, sourced from published systems, as DTCG JSON, CSS and TS.

    @snowbros/tokens
  • 08

    adapters

    Share one loop with Lenis, GSAP or Motion and scrub their timelines — without bundling them.

    @snowbros/adapters
05 — Two vocabularies

Functional for tasks.
Expressive for stories.

Functional

240 ms · cubic-bezier(0.2, 0, 0, 1) · FLIP

Release queue
  • P3Docs: platform profiles
  • P1Pin: overflow ancestor warning
  • P2Scene: context-loss recovery
  • P1Split text: grapheme safety
  • P4Tokens: dark theme set

Short, quiet, interruptible. It explains where each row went — then gets out of the way.

Expressive

scroll-scrubbed · clip-path · counter-scale

Slower, decisive curves tied to the reader's own scroll. Reserved for moments that deserve them.

06 — Install

Give your agent
taste and discipline.

The skill teaches an AI agent the full loop — recon, direction, build, verify. The packages are the instruments it reaches for.

1 · Skill (Claude Code)
git clone https://github.com/snowbros-labs/creative-engineering
cp -r creative-engineering/skills/snowbros-creative ~/.claude/skills/
2 · Libraries (any bundler)
pnpm add @snowbros/motion @snowbros/fx
3 · Use
import { pin, scrub, timeline } from '@snowbros/motion';

const p = pin(section, { distance: '200vh' });
const tl = timeline().to('.title', { y: ['100%', '0%'] });
scrub(tl, p.progress, { smooth: 10 });
