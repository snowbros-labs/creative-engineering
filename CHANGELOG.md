# Changelog

Notable changes to this repository. Per-package changelogs are generated by Changesets once
publishing starts.

## [Unreleased] — 0.1.0

### Added

- `@snowbros/core`: shared priority ticker (single rAF), easings + cubic-bezier solver, analytic and
  interactive springs, lifecycle scopes, signals, capability/device-tier detection, media contexts with
  `reduced-motion` / `full-motion` keywords, interaction contract types.
- `@snowbros/motion`: `animate`, `timeline`, `stagger`, `scrollProgress`, `scrub`, `scrollVelocity`,
  `pin` (CSS sticky), `horizontalScroll`, accessible `splitText`, `inView`, `flip`, `viewTransition`,
  `reveal` / `revealText`.
- `@snowbros/fx`: magnetic, cursor, tilt, scramble, drawPath, imageReveal, marquee, seeded gradient
  noise, flowField, spotlight.
- `@snowbros/scene`: managed three.js stage, quality governor, camera rig, orbit inertia, pointer
  parallax, model loader, gradient material, studio environment, particle field, `withFallback`,
  disposal utilities.
- `@snowbros/react`, `@snowbros/elements`, `@snowbros/tokens`, `@snowbros/adapters`.
- `skills/snowbros-creative`: the AI skill — workflow, modes, pattern catalogue, platform profiles and
  the `detect-stack` / `audit-motion` scripts.
- Project website (`website/`), playground and dashboard demos (`apps/showcase`).
